# Zapret Panel CachyOS

Персональная версия GTK-панели для управления Zapret/Flowseal на CachyOS и Arch Linux. Интерфейс оформлен в тёмной фиолетово-сиреневой палитре: скруглённые карточки, мягкие акценты и контрастный текст.

## Возможности

Панель отображает состояние службы и активный профиль, позволяет выбирать и применять профили, управлять автозапуском, запускать сеточную проверку и выполнять предусмотренные установленным `zapret-sonar` действия обновления.

## Требования

- CachyOS или Arch Linux
- Python 3, PyGObject и GTK 3
- Установленные Zapret, `zapret-sonar` и системная Zapret Panel с административным helper `zapret-panel-admin`
- PolicyKit для административных действий

Эта сборка меняет оформление пользовательской панели. Она **не поставляет движок Zapret, профили Flowseal, правила обхода блокировок или root-helper** и не меняет их системные файлы.

## Установка

Скопируйте `zapret-panel` в `~/.local/bin/zapret-panel`, сделайте исполняемым и настройте ярлык приложения так, чтобы `Exec` указывал на этот файл. Для отката удалите пользовательскую копию и ярлык: системная версия останется нетронутой.

Пример:

```sh
install -Dm755 zapret-panel ~/.local/bin/zapret-panel
```

Системный desktop entry может быть скопирован в `~/.local/share/applications/`, затем в его поле `Exec` нужно указать `~/.local/bin/zapret-panel` (с абсолютным путём).

## Примечания

- Профили и стратегия принадлежат установленной системе Zapret; выберите профиль в интерфейсе и проверьте его в своей сети.
- Встроенная проверка сети не подтверждает, что Discord screen share виден каждому зрителю: это также зависит от соединения, клиента, кодека и маршрута до конкретного участника.
- Не запускайте панель от root.
- Сборка локальная и персональная; это не официальный проект Ryoku, Zapret или Flowseal.
